## Study summary

Seven vaginal samples from five women (three HIV-positive, two HIV-negative controls) in Lagos, Nigeria, profiled by PacBio HiFi full-length 16S rRNA sequencing of the V1–V9 hypervariable region. Two of the three HIV-positive participants provided paired baseline and one-month post-ART samples; the third provided a baseline only.

This is a descriptive pilot. No inferential statistics are reported. Every number in the manuscript is traceable to the raw reads deposited in the European Nucleotide Archive (BioProject [PRJEB124225](https://www.ebi.ac.uk/ena/browser/view/PRJEB124225)) and to the analysis outputs generated by the scripts in this repository.

Key descriptive findings:

- 296 ASVs across 7 samples, dominated by *Lactobacillus* (mean 56.8%).
- Three community states observed: *Lactobacillus*-dominant (four samples), *Bifidobacterium*-dominant (one HIV-negative control), and *Gardnerella*/*Shuttleworthia*-dominant (two samples).
- *Lactobacillus* mean relative abundance did not differ consistently by HIV status (HIV-positive baseline 66.3%, HIV-positive one-month post-ART 49.9%, HIV-negative controls 49.3%).
- Opposite one-month ART trajectories in the two paired participants: PND02 declined from 99.9% to 0% *Lactobacillus*; PND03 rose from 0% to 99.8%.
- Among 84 *Lactobacillus* ASVs, *L. iners* accounted for 74.1% of *Lactobacillus* reads and *L. crispatus* for 10.6%. Ten *Lactobacillus* ASVs returned no significant BLAST hit and are reported as candidate divergent lineages (not as novel species).

## Pipeline

Run the scripts in numeric order. Each step is idempotent, so re-running from scratch is safe.

| Step | Script | Input | Output |
|---|---|---|---|
| 01 | `01_dada2_reprocess.R` | Raw `*.hifi_reads.fastq.gz` | `reanalysis/intermediate/filtered/*.fastq.gz`, `reanalysis/outputs/csv/read_tracking.csv` |
| 02 | `02_taxonomy_from_filtered.R` | `reanalysis/intermediate/filtered/*.fastq.gz` | `seqtab_final.rds`, `taxonomy_final.rds`, `asv_sequences_final.fasta` |
| 03 | `03_audit.R` | `seqtab_final.rds`, `metadata_corrected.csv` | `reanalysis/outputs/csv/audit_*.csv` (per-sample summary, genus %, pathogen %, group means, trajectories) |
| 04 | `04_figures_main.R` | audit CSVs | `figures/Figure1*`, `Figure2*`, `Figure3*` (PNG + PDF) |
| 05a | `05a_blast_prep.sh` | Raw NCBI BLAST hit tables | `reanalysis/blast/lacto_nt_final.csv` |
| 05b | `05b_blast_fetch_species.py` | `lacto_nt_final.csv` | `reanalysis/blast/accession_species_master.tsv` |
| 05c | `05c_blast_extract_missing.R` | ASVs not in first BLAST | `reanalysis/blast/missing_29.fasta` |
| 06 | `06_assign_species.R` | `lacto_nt_final.csv`, species TSV | `reanalysis/outputs/csv/table_lactobacillus_species_calls.csv`, `species_call_summary.csv`, `audit_lactobacillus_species_per_sample.csv` |
| 07a | `07a_build_supplementary.sh` | audit + species CSVs | `Supplementary/` (S1–S4 CSV, README, MANIFEST) |
| 07b | `07b_build_heatmap.R` | `audit_genus_per_sample.csv` | `Supplementary/Supplementary_Figure_S1_heatmap_top20_genera.{png,pdf}` |

## Requirements

- **R** 4.3.3 or later
- **cutadapt** 5.2 (`pip install cutadapt` or `conda install -c bioconda cutadapt`)
- **NCBI BLAST+** (for species assignment against nt, or use NCBI web BLAST)
- **Python** 3.9+ (for `05b_blast_fetch_species.py`; standard library only, no extra packages)

R packages:

## Reproducibility notes

    Read tracking. Every step of the pipeline writes read counts to reanalysis/outputs/csv/read_tracking.csv, so the number of reads retained at each stage is auditable (see Supplementary Table S1).

    Species assignment. Species calls in Supplementary_Table_S3_species_calls.csv carry an explicit reason column that records the identity of the top BLAST hit, its % identity and query coverage, the second-best named hit, and the resulting call. Ambiguous ASVs (top two named hits both ≥99% identical) are flagged rather than forced.

    Figure and table source. Every figure and table in the manuscript traces to a CSV in reanalysis/outputs/csv/ or reanalysis/outputs/tables/. The mapping is documented in Supplementary/README.md.

    No inferential statistics. The study is descriptive. No DESeq2, PERMANOVA, or hypothesis-testing outputs are included.
