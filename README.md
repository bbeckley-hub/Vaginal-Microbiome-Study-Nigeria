# Vaginal Microbiome Study – Nigeria

**Impact of Antiretroviral Treatment on Vaginal Microbiome Composition in People Living with HIV**

This repository contains the complete R analysis pipeline and supplementary data for the manuscript:

> *"Impact of Antiretroviral Treatment on Vaginal Microbiome Composition in People Living with HIV"*  
> Authors: Adesola Olalekan, Brown Beckley, Ogunsanya Oluwabunmi, Felix Agomma, Olarenwaju Ademuyiwa  
> Affiliation: University of Lagos, Nigeria; University of Ghana; KNUST, Ghana; Onikan General Hospital, Lagos.

## Project Overview

We used PacBio long‑read 16S rRNA sequencing to characterise the vaginal microbiome of five women in Lagos, Nigeria – three HIV‑positive (two with a one‑month follow‑up after ART initiation, one with only a baseline) and two HIV‑negative controls – yielding seven samples. Our objectives were to compare microbiome composition by age, *Lactobacillus* diversity, pathogen prevalence, strain consistency, and the effect of ART, and to identify potentially novel bacterial taxa.

All raw sequencing reads are deposited in the NCBI Sequence Read Archive under accession **PRJEB124225**.

## Input Data

The scripts assume the following files are present in the **parent directory** (i.e., the directory containing the `Rscripts/` folder). These files are **not** included in this repository due to size, but they can be generated or obtained as follows:

- `metadata.csv` – Participant metadata (provided as Supplementary Table S1).
- `seqtab_nochim.rds` – ASV table (generated by script 01).
- `taxonomy_with_species.rds` – Taxonomy table (generated by script 01).
- `NBLAST_asvs.fasta (104 ASVs).xlsx` – BLAST results for *Lactobacillus* ASVs (provided as Supplementary Table S2 data).
- `NBLAST_asvs.fasta_342 ASVs.xlsx` – BLAST results for all ASVs (used in script 09).
- SILVA reference files (`silva_nr99_v138.1_train_set.fa.gz` and `silva_species_assignment_v138.1.fa.gz`) – must be downloaded from Zenodo (see script 01 for details).

## Script Descriptions and Order of Execution

Run the scripts in numerical order (01 to 10). Each script reads intermediate files generated by previous scripts, so it is important to run them sequentially.

| Script | Purpose | Outputs |
|--------|---------|---------|
| `01_dada2_preprocessing.R` | Process raw PacBio FASTQ files: filter, denoise, infer ASVs, remove chimeras, assign taxonomy against SILVA. | `seqtab_nochim.rds`, `taxonomy_with_species.rds`, `asv_sequences.fasta` |
| `02_phyloseq_setup.R` | Load ASV table, taxonomy, metadata; create and save phyloseq object. | `vaginal_microbiome_phyloseq.rds` |
| `03_alpha_beta_diversity.R` | Calculate alpha diversity (Shannon, Observed), perform PCoA, PERMANOVA. | `Figure2A.png`, `Figure2B.png`, `permanova_age_hiv.txt` |
| `04_genus_composition.R` | Generate genus-level bar plots (all genera and rare grouped) and top‑20 heatmap. | `Figure1A.png`, `Figure1B.png`, `Supplementary_Figure_S1.png` |
| `05_lactobacillus_analysis.R` | Extract *Lactobacillus* ASVs, read BLAST species assignments, save species table. | `lactobacillus_abundances.csv`, `Supplementary_Table_S2_Lactobacillus_species.csv` |
| `06_pathogen_analysis.R` | Extract pathogen genera, create bar plot and presence/absence table. | `Figure3.png`, `Table1_pathogen_prevalence.csv` |
| `07_differential_abundance.R` | Run DESeq2, produce volcano plot and full results table. | `Figure4.png`, `differential_abundance_full.csv` (renamed to Table S4) |
| `08_jaccard_analysis.R` | Compute Jaccard distances and within‑group means. | `Supplementary_Table_S5_Jaccard_distances.csv`, `jaccard_within_means.csv` |
| `09_novel_microbe_detection.R` | Parse BLAST results for all ASVs, identify novel candidates (<97% identity). | `Supplementary_Table_S6_novel_candidates.csv` |
| `10_art_effect.R` | Generate bar plot showing *Lactobacillus* abundance before/after ART in paired samples. | `Figure5.png`, `Figure5_data.csv` |

## Usage

1. Clone this repository and set the working directory to the repository root:

```bash
git clone https://github.com/bbeckley-hub/Vaginal-Microbiome-Study-Nigeria.git
cd Vaginal-Microbiome-Study-Nigeria
```

2. Place the required input files (`metadata.csv`, FASTQ files, BLAST Excel files, and SILVA reference files) in the repository root.

3. Run the scripts in order:

```bash
Rscript Rscripts/01_dada2_preprocessing.R
Rscript Rscripts/02_phyloseq_setup.R
Rscript Rscripts/03_alpha_beta_diversity.R
Rscript Rscripts/04_genus_composition.R
Rscript Rscripts/05_lactobacillus_analysis.R
Rscript Rscripts/06_pathogen_analysis.R
Rscript Rscripts/07_differential_abundance.R
Rscript Rscripts/08_jaccard_analysis.R
Rscript Rscripts/09_novel_microbe_detection.R
Rscript Rscripts/10_art_effect.R
```

All output files (figures, tables, RDS objects) will be written to the repository root.

## Supplementary Files

The `Supplementary_files/` folder contains all supplementary tables cited in the manuscript:

- **Supplementary Table S1**: Participant metadata (`metadata.csv`)
- **Supplementary Table S2**: *Lactobacillus* species assignments and BLAST results
- **Supplementary Table S3**: Alpha diversity values (Observed, Shannon) per sample
- **Supplementary Table S4**: Full DESeq2 results for all 163 differentially abundant ASVs
- **Supplementary Table S5**: Pairwise Jaccard distance matrix
- **Supplementary Table S6**: List of 39 candidate novel ASVs (<97% identity)

Additionally, raw data for Figure 5 (`Figure5_data.csv` and `Figure6_data.csv`) are provided in the `extra/` subfolder.
